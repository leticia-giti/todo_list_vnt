# To-Do List

Aplicação web de gerenciamento de tarefas desenvolvida com **HTML, CSS e JavaScript**. O projeto tem como objetivo aplicar e consolidar conceitos fundamentais de desenvolvimento web, especialmente estruturação de páginas, estilização, manipulação do DOM e interação com o usuário.

## Sobre o projeto

O To-Do List permite o gerenciamento de tarefas por meio de uma interface simples e objetiva.

O projeto está sendo desenvolvido de forma incremental, acompanhando o aprendizado das tecnologias utilizadas e incorporando novas funcionalidades conforme o desenvolvimento avança.

## Funcionalidades

- [ ] Adicionar tarefas
- [ ] Listar tarefas
- [ ] Marcar tarefas como concluídas
- [ ] Remover tarefas
- [ ] Editar tarefas
- [ ] Filtrar tarefas
- [ ] Persistir tarefas utilizando `localStorage`

> As funcionalidades serão implementadas gradualmente durante o desenvolvimento do projeto.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Clone o repositório:

```bash
git clone https://github.com/leticia-giti/todo_list_vnt.git
```

Acesse o diretório:

```bash
cd todo_list_vnt
```

Abra o arquivo `index.html` em um navegador.

Também é possível utilizar uma extensão como o **Live Server** no Visual Studio Code para executar a aplicação durante o desenvolvimento.
